# Diagramas de PMP Suite V2.0

Revisión del 14 de octubre de 2026. Las fuentes `.puml` son editables; los SVG son su representación local. Los bloques PlantUML de los Markdown se mantienen sincronizados con esas fuentes. No se envían archivos a servicios de diagramación.

El manual incorpora la topología local. Los modelos amplios se consultan en SVG con zoom y sus vistas temáticas; no se reducen al ancho de una página ilegible.

## Proceso BPMN

[AS IS editable](../../BPMN/BPMN_AS_IS_V2.0.bpmn) y [vista](../../BPMN/BPMN_AS_IS_V2.0.svg) describen el contexto histórico. [TO BE editable](../../BPMN/BPMN_TO_BE_V2.0.bpmn) y [vista](../../BPMN/BPMN_TO_BE_V2.0.svg) conservan lanes, movimientos y el retorno de rechazo QA por Bodega hacia Lab. Son modelos descriptivos, no procesos ejecutables. Las cuatro vistas de detalle existentes en esa carpeta facilitan ampliar el proceso.

## Criterios de lectura

Las cardinalidades del ERD se contrastaron con `05_BaseDatos/schema_actual.sql`: ubicación, asignaciones, usuario registrador de activo y algunos vínculos históricos admiten nulos. El origen de stock por evento es único cuando está informado. Las vistas temáticas muestran un subconjunto conectado; el ERD general conserva los demás vínculos. El modelo conceptual expresa entidades del dominio, no tablas adicionales.

El ciclo 11 representa el rechazo QA con retorno conectado al nuevo despacho Lab. La recepción inicia el SLA; el dictamen no confirma salida. El flujo de instalación distingue resultado operativo de retorno por falla. Las secuencias de análisis incluyen solicitud y respuesta autorizadas.

## Reproducción local

Se utilizó PlantUML 1.2026.1 con Java y Smetana. Para regenerar, usar un JAR verificado y ejecutar desde la raíz:

```powershell
java '-Djava.awt.headless=true' -jar <ruta-local-plantuml.jar> -charset UTF-8 -tsvg 'Documentacion Capstone/Artefactos Metodologia Cascada/Diagramas_PlantUML/*.puml'
java '-Djava.awt.headless=true' -jar <ruta-local-plantuml.jar> -charset UTF-8 -tsvg 'Documentacion Capstone/Artefactos Metodologia Cascada/Diagramas_PlantUML/Vistas_Detalle/*.puml'
```

Para BPMN, usar un editor local compatible con BPMN 2.0 y exportar el XML conservado. No hay un script `08_Pruebas/verificar_documentacion.py` en esta copia; se retiró esa instrucción inexistente.

Los resultados actuales y limitaciones están en [Estado y pendientes](../../ESTADO_Y_PENDIENTES.md).
